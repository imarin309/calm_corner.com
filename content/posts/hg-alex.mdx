## はじめに

実は僕はガンダム作品の中で:large[「ポケットの中の戦争」がすごい好き]なんです！

無邪気に戦闘機や戦争に憧れている少年が戦争の悲惨さを目の当たりにし成長していく物語は、平和な日本で暮らしている私たちに語りかけるメッセージ性を感じます。

6話完結のOVA、今なお見劣りしない作画のクオリティの高さから、個人的にはガンダム初めての人には一番おすすめしたい作品です。

そして今回制作するアレックスは

- ニュータイプ専用のガンダムというかっこいい設定
- チョパムアーマーと呼ばれる装甲を装備して耐久性を向上させるといった渋い機構
- 初代ガンダムに明るい青を基調に変えたシンプルなデザイン

といったガンダム好きを刺激する要素満載で、:large[僕はアレックスがイチオシ機体]なんです、、！

といった感じでアレックスを制作、塗装していきたいと思います( ´ ▽ ` )

HGアレックスの個人的セールスポイントは上記写真の:large[チョパムアーマーを付け替えできる]ことです！

22年前の1600円のキットで、こんなに印象を変えられるギミックがあるのは感動。
クロスボーンガンダムX1のHGとかはマントは付属していなかったりしていたので、22年前のキットでこの遊びができるのは感動です。

一方で、色分けについては最近のHGと比べると少し物足りなさを感じます。
例えば背面のバーニアは成形色のまま白一色だったり、腰部分のV字マークも色分けされていません。

今回のテーマは:red[:large[νガンダムっぽいカラーリングにしたい！]]

アレックスは本来一年戦争末期にアムロに届けられるという最中に、ジオン軍の妨害にあい大破するという設定だと思います。
もしそれがアムロに届けられたら、どんな活躍をしていたのかみたいな思いを込めてこのテーマにしてみました。

具体的にやることとしては:blue[アレックスのメインカラーである明るい青を紺色にする]感じで塗装します。

あと、個人的に今までのガンプラ塗装の課題としてスミ入れが全然できていなかったことがありました。
よく一般的にスミ入れの技法としてモールドに塗料を流し込むようなやり方は、

- モールドが事前に塗装した塗料で埋まってて上手く流し込めない
- はみ出した部分を拭き取るのがうまくいかず汚しっぽくなってしまう

みたいな感じでうまくいっていませんでした。

そこで今回はこちらの「コピックモデラー Black」を使ってみます！

https://copic.jp/product/modeler/

> プラモデルなどのスジボリに陰影をつける用途に利用するもので、ディテールアップにご利用ください。
0.03を超えた驚異的なペン先の細さ0.02で、スジボリの細い模型やカプセルトイ等へのスミイレが手軽に行えます。

コピックペンは模型店の塗料売ってるあたりでよく見かけていて気になっていたのですが、プラモデルのスミ入れ用のものがあると聞いて今回試しに買ってみました。
（リアルの店舗には探しても売ってなかったのでヨドバシの通販で買ったよ。）

今回はこのペンでスミ入れしてみて、いい感じにできるか見てみたい。

### 塗る

水性塗料ファレホで筆塗りしていきます！

使用した道具

| 項目 | 内容 |
| --- | --- |
| 筆 | 平筆、ドライブラシ |
| 塗料 | ファレホ（水性塗料） |
| 下地塗料 | メカカラー ホワイト プライマー |
| 白色 | メカカラー ホワイト |
| 紺色 | メカカラー TITAN DARK BLUE + メカカラー PURE BLACK |
| オレンジ | メカカラー YELLOW + メカカラー RED |
| トップコート | ファレホ メタルメディウム, GLOSS VARNISH |

## 終わり

今回はHGアレックスを制作、塗装しました。
実は、美プラに比べてガンプラの制作はちょっとモチベーションが落ちていました。

今回のアレックスの制作は、旧キットだからか成形色の塗り分けが少なく塗装のしがいがあったし、スミ入れをいい感じにできた成功体験があり、非常に楽しくてガンプラ自体のモチベが上がりました。

今度は今回感じた反省点を活かすような感じで制作したいです。
