## 1. 筆塗りとは

筆塗りとは、その名の通り塗料を筆先につけて手で塗装していく方法です。
特徴としては主に3点あるかなと思います。

<Box title="筆塗りの特徴">
- 始めるためのコストが安い
    - 筆と塗料のお金くらい、3000円くらい
- 準備と片付けが楽で、机の上で少しずつできる
    - 筆とパレットと水を出すだけ！
- 部分塗装や小さい修正がしやすい
    - 細い筆など使えば細かいところも（難しいですが）塗装しやすい
</Box>

とはいったもののデメリットもあって、:marker[綺麗にムラなく塗るためのコツを掴むのは少し難しいです。]
例えば、塗料をどのくらい希釈するのかとか、はみ出さないように筆を動かす感じとか、言葉では説明しにくいコツが多くあるように思います。

<Speech>
    ただ、そのデメリットを補うくらい手軽さや実際に手を動かして塗っていく楽しさに魅力があるぽよ。
</Speech>

## 2. 使う道具

- 筆
- 塗料
- パレット
- 筆洗い用の水入れ（紙コップ）
- 筆の水を取る布や紙（ティッシュ、キッチンペーパー）
- 綿棒（はみ出しを拭き取る）
- パーツの持ち手（クリップ、持ち手棒）
- 乾燥台

大まかな塗装の方針は下記のような形です。

<Box title="今回の塗装の方針">
1. 下地はファレホのプライマーを筆で塗る
2. その上からファレホで色を塗る
3. トップコートは缶スプレーのものを使う
</Box>

### 塗料について

今回は水性塗料のファレホとMr.Hobbyのトップコートを使っていきます。

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/pokepla-pichu/polepla-pichu-painting.webp", alt: "ファレホ_Mr.Hobby_使用塗料", caption: "今回使う塗料" },
  ]}
/>

私は主に使用塗料としてこのファレホを使っています。

https://hobby.volks.co.jp/brand/vallejo/

ファレホは水性アクリル塗料のため溶剤のような匂いがほとんどないため使いやすく愛用しています。

<Speech>
    ファレホはいいぞ。販売しているお店が少ないのが難点。。。
</Speech>

### 塗る

<BuildStepGroup>
<BuildStep number={1} title="下地をファレホのプライマーで塗る" materials={["ファレホ メカプライマー ホワイト"]}>
**まず最初に下地を塗っていきます。**
プラスチックにそのまま塗料を塗っていくと、少し弾いてしまうので下地を塗って塗料を塗りやすい膜を作るようなイメージです。
</BuildStep>
<BuildStep number={1.1} title="よく振ってパレットに出す" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-primer-paint.webp", alt: "ファレホ_プライマー_パレットに出す", caption: "よく振ってからパレットに出す" },
]}>
**パレットに下地塗料を出します。**
地味に重要なのが、:marker[塗料を出す前に混ぜること]です。ファレホだと蓋を押さえてよく振ります。そのままだと顔料が沈んでいるのでシャバシャバになっていたりします。
プライマーは水で薄めずに、そのまま使います。

</BuildStep>
<BuildStep number={1.2} title="筆先に少しだけ塗料をつけるイメージで" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-primer-fude.webp", alt: "ファレホ_プライマー_筆先に塗料をつける", caption: "筆先に少しだけつける" },
]}>
    :marker[筆に少しだけ塗料をつけるイメージで、塗料をつけます。]
    早く塗装を終わらしたい、と思って焦って塗っているとドバッとつけがちですが、ゆっくりと塗料をつけることが大事です。
</BuildStep>
<BuildStep number={1.3} title="下地を塗っていく" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-primer2.webp", alt: "ポケプラ_ピチュー_下地塗装中", caption: "薄く塗っていく" },
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-primer1.webp", alt: "ポケプラ_ピチュー_下地塗装中_別パーツ", caption: "ムラができないように薄く" },
]}>
**下地を塗っていきます。**
:marker[ムラができないように薄く]塗ります。
</BuildStep>
<BuildStep number={1.4} title="塗った後" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-primer-after.webp", alt: "ポケプラ_ピチュー_下地塗装後", caption: "下地を塗った後" },
]}>
ちょっと白くなっててかわいい。
</BuildStep>
<BuildStep number={2} title="色を塗る" />
<BuildStep number={2.1} title="パレットに出して、水で薄める" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color1.webp", alt: "ファレホ_塗料をパレットに出す", caption: "よく振ってからパレットに出す" },
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color2.webp", alt: "ファレホ_水で希釈", caption: "スポイトで一滴ずつ水を足して薄める" },
]}>
**下地と同じように、よく振ってからパレットに出します。**
塗料を使う時は水などで薄めたりします。
どのくらいの割合で希釈するかは難しいのですが、:marker[希釈したときに水っぽくなりすぎないようないい感じの塩梅を探します。]僕はスポイトで一滴ずつ垂らして調節しています。

※ファレホのいいところなのですが、ラッカー塗料だと希釈するときは薄め液を使用する必要があるのですが、ファレホは精製水や水で希釈することができます。
</BuildStep>
<BuildStep number={2.2} title="塗っていく" materials={["ファレホ ゲームカラー、モデルカラー"]} images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color-white1.webp", alt: "ポケプラ_ピチュー_目の白を塗装", caption: "目の白を塗る" },
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color-yellow.webp", alt: "ポケプラ_ピチュー_黄色を塗装", caption: "黄色を塗る" },
]}>
    **それぞれの色を塗っていきます！**
    コツとしてはこんな感じのことを意識します。
    :marker[・一度で塗りきろうとせず、薄く何回も重ねる。]
    :marker[・塗料を筆につけすぎない]
    :marker[・重ね塗りするときは乾いてから次を塗る。]
    乾いたかどうかは、30分くらい置いて、触ってべたつかなければOKにしています。
</BuildStep>
<BuildStep number={2.3} title="ムラになっているところは重ね塗りしていく" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-mura-before.webp", alt: "ポケプラ_ピチュー_1回目塗装のムラ", caption: "1回目はムラができる" },
    { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-mura-after.webp", alt: "ポケプラ_ピチュー_重ね塗り後", caption: "2、3回重ね塗りした後" },
]}>
    1回目塗ったときは左の写真のようにムラができるので、2、3回ほど重ね塗りしてムラをなくしていきます。
</BuildStep>
<BuildStep number={2.4} title="はみ出しを直す" images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-hamideteru-before.webp", alt: "ポケプラ_ピチュー_黒のはみ出し", caption: "黒が少しはみ出している" },
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color-hamidashi.webp", alt: "ポケプラ_ピチュー_はみ出しを補正", caption: "上から色を重ねて補正する" },
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color-hamidashi2.webp", alt: "ポケプラ_ピチュー_はみ出しを補正_2", caption: "綿棒で拭いて消すこともできる" },
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-color-hamidashi-after.webp", alt: "ポケプラ_ピチュー_はみ出し補正後", caption: "補正した後" },
]}>
    ピチューの黒いところが少しはみ出してしまったので、上から色を重ねたりして補正します。
    :marker[ファレホは水性塗料なので塗ってすぐなら水で湿らせた綿棒で拭き取ることもできます。]
    乾くと落ちにくくなるので、はみ出したら早めに拭きます。
</BuildStep>
<BuildStep number={3} title="缶スプレーでトップコートを塗る" materials={["つや消し(Mr.スーパークリアー つや消し)"]} images={[
  { src: "https://assets.calm-corner.com/posts/pokepla-pichu/pokepla-pichu-topcoat.webp", alt: "ポケプラ_ピチュー_トップコート", caption: "最後にトップコートを吹く" },
]}>
**最後にトップコートを吹きます。**
塗料そのままだと時間が経つと劣化して取れたりすることがあるので、トップコートを吹いて補強するイメージです。
トップコートを吹く前は塗料が乾くまで置いておきます。僕はいつも半日くらい乾かしてから吹いています。
:marker[一度に厚く吹くと塗装面が荒れることがあるので、少し離して薄く2、3回に分けて吹きます。]

<Caution>
今回使ったMr.Hobbyのトップコートの缶スプレーはラッカー系で匂いがあるので、ここだけはベランダなど換気できる場所でやるのがおすすめです。
</Caution>

</BuildStep>
</BuildStepGroup>
