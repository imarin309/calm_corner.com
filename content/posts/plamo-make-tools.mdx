## 1. 組み立てで使う道具

### ニッパー・片刃ニッパー

言わずもがな、パーツをランナーから切り離すのに使います。

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/plamo-make-tools/tools_nipper.webp", alt: "プラモ道具_ニッパーと片刃ニッパー", caption: "ニッパー2本" },
  ]}
/>

500円くらいの初心者用のニッパーと片刃ニッパーと言われるちょっと高級なニッパーの二つを使ってます。
使い方としては、まず初心者用のニッパーでランナーからざっくり切り離してから、片刃ニッパーでゲートを落とす感じです。

刃先のカバーをつけて保管しています。

<Speech>
片刃ニッパーは最初使った時に切れ味の気持ちよさに感動するので、ぜひ一回使ってみてほしいぽよ。
</Speech>

### デザインナイフ

片刃ニッパーで切ったあとに残るゲート跡を削るのに使っています。
使用頻度はあまり高くないです。

  ]}
/>

### カッターマット

デザインナイフとか、刃物を使う時に下に敷くような形で使っています。

  ]}
/>

### ペンチ

プラモを組み立てる時に使います。
パーツ同士をはめるときに、手でやってもあまりハマらない時に使います。

## 2. 筆塗り塗装で使う道具

### 筆

筆塗りなので、その名の通り筆です。
個人的に必須なのは細い面相筆と極細の丸筆です。

細かい部分は極細の丸筆を使い、それ以外は面相筆を使っています。

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/plamo-make-tools/tools_fude.webp", alt: "タミヤ_モデリングブラシ_面相筆と丸筆", caption: "筆" },
  ]}
/>

筆は100均の筆とか画材屋さんの筆など色々使ったりしましたが、タミヤさんのモデリングブラシが買いやすいし安価だし重宝しています。

https://www.tamiya.com/japan/products/list.html?genre_item=501050

<Speech>
筆は模型屋さんや画材屋さんなどいろんな場所で売ってるので、ウィンドウショッピングをするのも楽しいぽよ。
</Speech>

### 塗料

ファレホの塗料を使っています。
ファレホは水性塗料なので、匂いが少なくて部屋でも塗りやすいです。

実は最初は水性ホビーカラーを使っていたのですが、ファレホはアクリル塗料なので溶剤特有の匂いがなく気軽に塗装できるので変えました。
そしてファレホは塗料を薄めるのが、薄め液ではなく水でいいのが本当に使いやすい。

あとパッケージがかっこいいのもポイント( ^ω^ )

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/plamo-make-tools/tools_painting.webp", alt: "ファレホ_水性アクリル塗料", caption: "ファレホ" },
  ]}
/>

新しく買うときは下地を塗る「プライマー」と「モデルカラー、メカカラー、ゲームカラーなどの塗料」「バーニッシュ」を買えばいいと思います。

ざっくり

- 塗料を塗る前にプライマーで下地を塗る
- 塗料を塗って塗装する
- バーニッシュで塗膜を保護する

といった形。

### スポイト

ファレホを薄めるときに水をパレットにたらす時に使います。
使うときは一滴ずつ垂らして調整していきます。

ペーパーパレットを使っています。

正直100均のペーパーパレットで十分だと思います。

一回ウォーターパレットを試してみたけどあまり上手く使えなかったぽよ。評判いいからどこかでまたチャレンジしたいぽよ
</Speech>

### 筆洗い

水を入れておいて、筆を洗うものです。

複数の色で塗装する時とかは水が途中から汚くなるので、水を入れるスペースが複数あると便利です。

<ImageGallery
  images={[

  ]}
/>

僕はサクラクレパスさんの筆洗を使っています。
スペースが二つあるし、筆を置くくぼみがあって作業がしやすいのでおすすめです。

https://www.craypas.co.jp/products/painting-school/023/0090/147414.html

<Speech>
ネットで調べるときは「筆洗」で検索すると商品が出てくるぽよ。
</Speech>

### キッチンペーパー

地味にこのペーパーが重要な気がします。

筆洗で筆を洗ったあとに筆から水をとったりする時に使ったり、毛先の塗料をとって量を調整するときに使います。

:marker[筆塗りするときは毛先の塗料が多すぎないことが重要（だと思う）ので、この子の役割は非常に重いです。]

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/plamo-make-tools/tools_paper.webp", alt: "プラモ道具_筆塗り用キッチンペーパー", caption: "キッチンペーパー" },
  ]}
/>

<Speech>
キッチンペーパーだと筆の毛先が傷つくと聞いたので、どこかで使うものは見直したいと思ってるぽよ
</Speech>

### 綿棒

100均で売ってる綿棒です。
筆塗りしたあとにはみ出した時に補正するときに使ったりします。

グラデーションのように塗るときにも、境界線をぼかすときにつかったりしていて結構用途は広いです。

筆塗りするときにパーツを持つ時、塗った後に乾燥させる時に使います。
これらは模型店によく売ってあるものを使っています。

乾燥台に関しては100均で売ってある猫の爪とぎで代用できます。

### トップコート

缶スプレーのトップコートです。
塗装した後塗膜を保護するのに使っています。

ファレホのバーニッシュを筆塗りすることもあるのですが、トップコートを吹いて簡単に仕上げることもあるのでそういう時に使います。

ただ、缶スプレーなのでベランダとか換気のいいところで吹くのがおすすめです。
