## 2. 制作工程

### 台座に固定

今回はプラモを台座に固定する感じで制作してみました。

台座はこちらの直径10cmの木製ベースを、固定するにはタミヤの瞬間接着剤のゼリータイプを使用しました。

https://www.mr-hobby.com/ja/products/detail/2523

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/30ms-marical/30MS-marical-leg2.webp", alt: "30MS_マリカル_台座固定用の接着剤", caption: "接着剤" },
  ]}
/>

まず最初にポーズを決めて、台座に固定。
タミヤの瞬間接着剤は初めて使ったんですが、、、想像以上にちゃんと接着してくれました。
固定した後ちょっとさわっても全然ぐらぐらしない。

<Speech>
塗装したプラモは一つのポーズで残しておきたい気持ちがあったのでやってみましたが、なかなかいい感じ！
</Speech>

### 塗装

使った塗料はこちら

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/30ms-marical/30MS-marical-painting.webp", alt: "30MS_マリカル_使用したファレホ塗料", caption: "塗料" },
  ]}
/>

いつも通りファレホを使用しました。
白のプライマーで下地を塗って、ゲームカラーを中心に塗っていき、groos varnishで仕上げました。

REDがメカカラーなのは、半端に塗料が余ってて使い切りたかったからですね、、( ・∇・)

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/30ms-marical/30MS-marical-hair.webp", alt: "30MS_マリカル_髪の塗装", caption: "髪" },
  ]}
/>

髪は軽くハイライトを入れる感じで塗装しました。

モデルカラーのDEEPYELLOW(70915)にゲームカラーのデッドホワイト(72.001)を混ぜていてて、重ね塗りしていくたびに白の割合を増やしていきグラデーションをつけていきました。
俗にいう光のリングの部分はGRAZE MEDIUMで希釈して境界線をぼかす形で塗りました。

ただ、マリカルさんの元の髪色のクリーム色っぽい感じの色を作りたかったが、うまく作れずちょっと黄色っぽい色で塗りました。

<Speech>
調色のセンス、向上したいぽよ
</Speech>

<ImageGallery
  images={[
    { src: "https://assets.calm-corner.com/posts/30ms-marical/30MS-marical-face.webp", alt: "30MS_マリカル_褐色肌の顔塗装", caption: "顔" },
  ]}
/>

今回のマリカルさんは褐色女子！！！なので褐色の肌色を作ったんですが、結構むずい。

褐色肌色用のモデルカラーPRIMULA TAN FLESH(70.743)を使って色を作りました。
また、いつもはほっぺたや鼻の赤みはウェザリングマスターを使って表現していたのですが、今回は筆塗りで表現できないかなと思って肌色にモデルカラーのOLD ROSE(70.944)を混ぜる形で塗ってみました。
