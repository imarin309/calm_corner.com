こんにちは、あんぱんです！
今回は美プラを塗る時に、フェイスパーツに印刷されている目をマスキングペンで守って塗る方法について書いていこうと思います。

<Box title="対象の読者">
- 美プラの顔を塗りたいけど、印刷された目を守る方法が分からない
</Box>

<Speech>
マスキングテープでは難しいところも、塗って乾かすだけでマスキングできるのでおすすめです！
</Speech>

## 1. マスキングペンとは

使うものはこちらの「ミツワ・マスケット」です。

https://webshop.sekaido.co.jp/product/A120016

<ImageGallery
  images={[
        { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/maskingpen.webp", alt: "ミツワ_マスケット_マスキングペン本体", caption: "マスキングペン" },
    ]}  
/>

美プラのフェイスパーツは、目や眉がタンポ印刷されているものが多いです。
これはそのまま組み立ててすごいかわいいのですが、肌を塗装しようと思ったときに印刷されている部分をマスキングして行うのが難しいと思います。（少なくとも僕は、、）

マスキングテープを使うという手もあると思うのですが、目の部分を正確に貼るのは個人的には難しいです。

そこでこのマスキングペンを使うことによって、:marker[細かい部分でもマスキングしたい部分を隠す]ことができて便利です。

<Caution>
今回紹介しているミツワマスケットは水彩画用なので、水性塗料以外を使った塗装で行うとマスキングの膜が傷つくなどの問題が起こる可能性があるかも。
</Caution>

## 2. マスキングして塗ってみる

https://bandai-hobby.net/item/01_4233/

        { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/30MS-laranel-package.webp", alt: "30MS_ララネル_パッケージ", caption: "パッケージ" },
    ]}  
/>

今回はこの30MSシリーズのララネルさんのフェイスパーツを例に、フェイスパーツをマスキングして塗ってみます！

<BuildStepGroup>
<BuildStep number={1} title="マスキングペンを塗る" images={[
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-before.webp", alt: "30MS_ララネル_マスキング前のフェイスパーツ", caption: "マスキングする前" },
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-fude.webp", alt: "30MS_ララネル_筆でマスキングペンを塗る目元", caption: "筆で塗っていく" },

  ]}>
  マスキングペンをそのまま出すこともできるのですが、今回は細かい部分をマスキングするので細い筆を使ってマスキングペンで塗っていきます。
</BuildStep>
<BuildStep number={2} title="乾かす" images={[
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-after.webp", alt: "30MS_ララネル_マスキングペン塗布直後の目元", caption: "塗った状態、ちょっと怖い" },
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-after-dry.webp", alt: "30MS_ララネル_マスキングペン乾燥後の目元", caption: "乾いた後" },
  ]}>
塗り終えたら乾かします。大体2時間くらいで乾くので気長に待ちます。
</BuildStep>
<BuildStep number={3} title="塗装する" images={[
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-paint.webp", alt: "30MS_ララネル_フェイスパーツの肌塗装", caption: "ぬりぬり" },
  ]}>
  肌の色を塗装していきます。目の部分はマスキングされているので安心して塗れます。
</BuildStep>
<BuildStep number={4} title="マスキングを剥がす" images={[
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-hagasu.webp", alt: "30MS_ララネル_綿棒でマスキングを剥がす", caption: "綿棒で剥がす" },
    { src: "https://assets.calm-corner.com/posts/face-parts-maskingpen/masking-paintafter.webp", alt: "30MS_ララネル_マスキング剥離後の目元", caption: "綺麗になったね" },
  ]}>
  塗料が乾いたら綿棒を使って剥がしていきます。（今回は綿棒で行いましたが、付属のラバークリーナーで行った方が安全かも）
</BuildStep>
</BuildStepGroup>

完成！

肌色の部分だけ塗装できました！
（こうして拡大してみるとちょっと塗膜がごつごつしている気がしますがそれはご愛嬌ということで、、）

## 3. おわり

今回はマスキングペンを使ってフェイスパーツを塗る方法を紹介しました。

今は目の部分を塗装する技量がないのでマスキングする形を取りましたが、いずれはそこも含めて塗装したり描いたりできるようになりたい。
