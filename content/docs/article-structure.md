# 制作記事の構成ガイド

ガンプラ・美プラの筆塗り制作記事を、どういう流れで組み立てるかをまとめたもの。
記事を書くとき・直すときと、構成に迷ったときに読む。

- 文体のルールは `~/.claude/WRITING.md`
- 空欄の雛形は `content/docs/template.md`
- 実例は `content/posts/hg-alex.mdx`（この記事を起点に整理した）

## 記事全体の軸: 予告と回収

記事は「素組みで気になったこと」から「完成でどうなったか」までを1本の線でつなぐ。

```text
素組みで気になったところ
↓
制作方針: だからこう塗る / これを試す
↓
工程: 実際にやる
↓
完成: できたか、うまくいったか
```

前半で予告したことは、必ず後半で回収する。予告したのに工程や完成で触れていないと、読み手は「あれはどうなったの？」となる。

hg-alex での線:

| 予告（前半） | 回収（後半） |
| --- | --- |
| 素組み: 明るい青の配色、色分けが足りない | 工程: 紺色を作る・塗り分ける → 完成: νガンダムっぽくなったか |
| 制作方針: スミ入れがずっと失敗していた → コピックモデラーを試す | 工程: コピックモデラーでスミ入れする → 完成: スミ入れについて（うまくいった所・肩の失敗） |

## セクションごとに書くこと

### フロントマター

- `title`: `【筆塗り塗装】キット名 制作 | キャッチコピー`。美プラは `【美プラ筆塗り塗装】`
  - キャッチコピーは、今回のテーマか一番の見どころを一言で。「22年前のキットを紺色でνガンダム風に」
- `description`: 100〜120文字。キット名・塗装方法・テーマ・試したことを入れる（`/blog-generate-description`）
- `category`: `gunpla` / `girls-plamo` / `other`
- `coverImage`: 完成写真から選ぶ。カードで顔や頭が切れる場合は `coverImagePositionY`（0で上端、50で中央、100で下端）で調整する

### 冒頭

- 挨拶と「今回は〇〇を制作しました、筆塗りで塗装してみました」
- パッケージ写真の `<ImageGallery>` と、公式サイトの `<LinkCard>`

### この記事の要約

6項目の表。**本文を書き終えてから埋める**。本文に書いていないことは入れない。

| 項目 | 書くこと |
| --- | --- |
| 使用キット | 正式名称 |
| 塗装方法 | 筆塗り |
| 主に使った塗料 | ファレホ（水性塗料）など |
| 今回試したこと | 制作方針のテーマと挑戦 |
| 難しかったところ | 工程・完成で書いた失敗や反省 |
| 完成後の印象 | 完成セクションの感想を一言で |

### はじめに

作品・キャラ・機体への思い入れと、なぜこのキットを作ったか。
作品説明を長くせず、自分がどこに惹かれているかを書く。

### 素組み

キットのレビューにはしない。塗装方針への布石として書く。

1. 素組み全体の印象（正面・背面・特徴的なギミックの写真）
2. 良いところ（あれば）
3. **気になったところ・足りないところ**（色分け、成形色、デカールなど。該当箇所の写真を添える）
4. 「なのでこう塗装する」とつなぐ

3 がそのまま制作方針と工程の材料になる。写真は後で塗装後と比べられるよう、アングルを意識して撮っておく。

### 塗装

#### 制作方針

- 塗装メモの画像
- テーマ（カラーリングの狙い）と、そう決めた理由
- 今回の挑戦と、その背景（過去に困っていたこと、なぜその道具・技法を選んだか）

#### 塗る

- 使用した道具の表（筆、塗料、下地、色ごとのレシピ、トップコート）
- 作業時間
- `<BuildStepGroup>`

`<BuildStepGroup>` の区切り方:

- 「何を判断・工夫したか」で区切る。部位ごと（胴体・腕・頭部…）には分けない
- 部位ごとのサブステップ（`number={2.1}`）は、塗り方や技法が部位によって違うときだけ使う
- 調色に工夫がある色は「〇〇色を作る」として独立させ、割合を書く（「青9:黒1」）
- 素組みで気になったところ・今回の挑戦は、それぞれ独立したステップにする
- 写真は「手元」「塗り終わった結果」「本体のどこか分かる引き」を揃える
- 本文のないステップを作らない。写真だけなら caption で補うか、前後のステップにまとめる

制作前に塗装メモから見出しと撮影リストを作る場合は `/plan-build-steps` を使う。

美プラでは、髪・肌・服・フェイスで技法が大きく違う（ハイライト、チーク、デカールなど）ことが多い。その場合は部位ごとのステップにしてよい。

### 完成

- 全体の写真（ガンプラは正面、美プラは `<ThreeSixtyView>` があれば）
- テーマが実現できたか
- 今回の挑戦ごとに `###` 見出しを立て、うまくいったところと失敗したところを写真つきで書く
  - hg-alex: 「コピックモデラーでのスミ入れについて」
- `### 色々撮影する`: ポーズ・装備違いのギャラリー

### 終わり

- 今回やってみてどうだったかを数段落で
- 次にやりたいこと・反省を活かしたいこと
- 「ではまた( ＾∀＾)」などの軽い締め

壮大な教訓にはしない。

## 作業の流れと使うスキル

| タイミング | やること | スキル |
| --- | --- | --- |
| 素組み後 | 塗装メモを作る | |
| 制作前 | BuildStep の見出しと撮影リストを作る | `/plan-build-steps` |
| 制作中 | 撮影リストに沿って撮る | |
| 制作後 | R2 にアップロードした画像を記事に配置する | `/place-post-images` |
| 執筆 | 本文を書く（WRITING.md に従う） | |
| 仕上げ | alt・description・タイトルを埋める | `/blog-generate-alt`、`/blog-generate-description` |

## 書き終えたときのチェック

- [ ] 素組みで気になったところが、工程と完成で回収されている
- [ ] 今回の挑戦に、工程のステップと完成の見出しがある
- [ ] 本文のない BuildStep がない
- [ ] 要約の表が本文の内容と合っている
- [ ] 他の記事からコピーした文章が残っていない（塗料シリーズ名、キャラの部位など）
- [ ] 「後で書く」などのメモが残っていない
