ブログ記事のコンテンツレビューを実施してください。

## 対象ファイル

`$ARGUMENTS` で指定されたMDXファイルを読み込んでレビューしてください。
引数が空の場合は、レビュー対象のファイルパスを聞いてください。

## ペルソナ・記事で伝えたいこと

**想定ペルソナ**: 筆塗り塗装に挑戦したい・やり方を知りたいプラモデル初心者〜中級者
**記事で伝えたいこと**: 筆塗りで実際にどう塗装したのか、手順・テクニック・コツをわかりやすく伝える

## チェックリスト

### 【タイトル・メタデータ】

- [ ] タイトルは40-50文字（重要なキーワードを左側に配置）
- [ ] ディスクリプションは100-120文字（検索意図に応える内容）
- [ ] 記事内容がひと目でわかる簡潔な表現

### 【本文・ライティング】

- [ ] **ファーストビュー**（スクロール前）に解決策やキーワードが含まれている
- [ ] 見出し（H2/H3）を適切に使い、構造化されている
- [ ] 重要な箇所を太字（`<strong>`）や箇条書きで装飾している
- [ ] スマホで見た時に「一画面が文字で埋め尽くされていない」か（改行の調整）
- [ ] 誤字脱字はないか

### 【画像関連】

- [ ] **alt属性**（代替テキスト）に画像の内容を記述している
- [ ] ファイル名は `seo-checklist.webp` のように英単語で意味を持たせる
- [ ] 拡張子は **WebP**
- [ ] 容量は **100KB以下**
- [ ] 横幅は最大 **1200px** 程度（レスポンシブ対応を確認）

### 【ペルソナ・記事意図との整合性】

- [ ] **ファーストビューでペルソナに刺さるか**: 冒頭の数行を読んだとき、想定読者が「この記事は自分のためのものだ」と判断できるか
- [ ] **記事で伝えたいこと（HOW）が具体的か**: やり方・手順・コツなど、読者が実践できるレベルの情報が書かれているか
- [ ] **ペルソナが知りたい情報が揃っているか**: 想定読者の疑問に答えられているか

## 出力フォーマット

各チェック項目を以下の形式で出力してください：

```
### 【カテゴリ名】

- ✅ チェック項目: 問題なし（根拠を簡潔に）
- ⚠️ チェック項目: 改善推奨（具体的な改善案）
- ❌ チェック項目: 要修正（具体的な修正案）
```

最後に「総合評価」として、記事全体の改善優先度が高い項目を3つ以内でまとめてください。

## 最後に

記事本文の文字数も、本文テキストに含まれる文字（日本語・英数字・記号）を、全角・半角を問わず 1 文字としてカウントしてください。スペースおよび改行は文字数に含めず、その結果をあわせて記載してください。

## 注意事項

- 画像の容量・横幅はファイルの実体を確認できないため、MDX内の記述から判断できる範囲でレビューしてください
- タイトルの文字数カウントは日本語基準で行ってください
- フロントマターの `description` が未設定の場合はその旨を指摘してください
