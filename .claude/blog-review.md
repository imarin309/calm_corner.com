# Calm Corner のレビュールール

`~/.claude/skills/blog-content-review` が読む、Calm Corner 固有のルール。
共通の文体ルールはスキル側にあり、ここにはこのブログだけの型を書く。

## 書き手

- 書き手名は **あんぱん**（旧名 imarin）
- 旧名で書かれた過去記事は、名前を指摘しない

## 記事の種類と型

まず、制作記事か、ポエム・その他の記事かを判定する。片方の型をもう片方に当てはめない。
制作記事に定型の挨拶がなければ指摘するが、ポエム記事に挨拶がないのは正しい。

|            | 制作記事（ガンプラ・美プラ・フィギュア）                                                                                      | ポエム・その他                                                               |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| タイトル   | `【筆塗り塗装】キット名 制作 \| キャッチコピー`。美プラは `【美プラ筆塗り塗装】`                                              | 決まった型はない（「プラモ制作、筆塗り塗装するのは楽しいよ、という話」など） |
| 書き出し   | `こんにちは、あんぱんです！`                                                                                                  | 挨拶なし。見出しから本題に入る                                               |
| 導入       | 「今回は〇〇を制作しました、筆塗りで塗装してみました」＋「キット自体の感想も絡めながら〜書いていきたいと思います」            | 個人史から入る                                                               |
| 表         | `## この記事の要約` の表（使用キット/塗装方法/主に使った塗料/今回試したこと/難しかったところ/完成後の印象）＋使用した道具の表 | なし                                                                         |
| 結び見出し | `## 終わり`                                                                                                                   | `## おわり`                                                                  |
| 結びの一文 | `ではまた( ＾∀＾)` でほぼ固定                                                                                                 | 顔文字で終わる                                                               |

## 制作記事の構成チェック

制作記事は、先に `content/docs/article-structure.md` を読んでから、次を確認する。

- 素組みで気になったところが、制作方針 → 工程 → 完成で回収されている
- 今回の挑戦に、工程のステップと、完成の `###` 見出しがある
- `<BuildStepGroup>` が部位ごとの繰り返しになっていない。本文のないステップがない
- 要約の表が本文の内容と合っている。本文にないことが書かれていない
- 他の記事からコピーした文章が残っていない（塗料シリーズ名、キャラの部位など）
- 「後で書く」などの執筆メモが残っていない

締めは「うまくいった点 / 反省点」の見出しではなく、完成セクションで挑戦ごとに見出しを立て、`## 終わり` で次にやりたいことに触れる形。
古い記事の「うまくいった点 / 反省点」は誤りではないので指摘しない。
