# Calm Corner のレビュールール

`~/.claude/skills/blog-content-review` が読む、Calm Corner 固有のルール。
共通の文体ルールはスキル側にあり、ここにはこのブログだけの型を書く。

## 書き手

- 書き手名は **あんぱん**

## 記事の種類と型

まず、制作記事か、ポエム・その他の記事かを判定する。片方の型をもう片方に当てはめない。
制作記事に定型の挨拶がなければ指摘するが、ポエム記事に挨拶がないのは正しい。

|            | 制作記事（ガンプラ・美プラ・フィギュア）                                         | ポエム・その他                                                               |
| ---------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| タイトル   | `【筆塗り塗装】キット名 制作 \| キャッチコピー`。美プラは `【美プラ筆塗り塗装】` | 決まった型はない（「プラモ制作、筆塗り塗装するのは楽しいよ、という話」など） |
| 書き出し   | `こんにちは、あんぱんです。`                                                     | 挨拶なし。見出しから本題に入る                                               |
| 導入       | 「{キット名}を制作、筆塗り塗装しました！」＋素組みと塗装の比較写真（正面・背面） | 個人史から入る                                                               |
| 表         | なし                                                                             | なし                                                                         |
| 結び見出し | `## おわり`                                                                      | `## おわり`                                                                  |
| 結びの一文 | `<Speech>` の中で `ではまた( ＾∀＾)`                                             | 顔文字で終わる                                                               |

## 制作記事のチェック：読者のニーズに応えているか

制作記事は、先に `docs/plamo_article_reader_needs.md` を読み、そこにある読者のニーズを満たしているかで判断する。
テンプレートの見出しや順番に沿っているかは問わない。

まず「記事ごとに決め直す項目」を記事から読み取る（最も届けたい読者、中心的な疑問、この記事ならではの価値）。
読み取れなければ、それ自体を指摘する。

そのうえで、読者ごとに確認する。

- **① 作例を見たい人**：完成形が冒頭ですぐ伝わるか。全体・別角度の写真、見どころ、配色や加工の意図、素組みとの違いがわかるか
- **② 再現したい人**：塗料のシリーズ名・色名・色番号と、どこに塗ったかがわかるか。重要な工程が、自分で試せる程度に書かれているか。仕上がりのアップ写真があるか
- **③ 技法を学びたい人**：今回特に重要だった技法について、難しかった点・対処・やり直すなら変えることが書かれているか（制作記事なので網羅的な解説までは求めない）

足りない写真を指摘するときは、後から撮れる完成写真に限る。存在しない途中経過の写真や、曖昧な条件を推測で補う提案はしない。

## 書き忘れ・消し忘れ

- 他の記事からコピーした文章が残っていない（塗料シリーズ名、キャラの部位など）
- 「後で書く」などの執筆メモや、テンプレートの `//` コメントが残っていない
