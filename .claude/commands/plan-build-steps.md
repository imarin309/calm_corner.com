制作を始める前に、塗装メモの画像から `<BuildStepGroup>` の見出し案と、ステップごとの撮影リストを作ってください。
出力はチャットのみで、MDXには書き込まない。

## 入力

`$ARGUMENTS` で塗装メモの画像（ローカルパスまたは `https://assets.calm-corner.com/...` のURL）を受け取る。
下書きのMDXパスが一緒に渡された場合は、「組んでみた感想」「使用した道具」もあわせて読む。
画像の指定がなければユーザーに聞く。

塗装メモは、素組みの写真に矢印と注釈を書き込み、横にテーマ・改造・塗装の箇条書きを並べたもの（例: `hg-alex-plan.webp`）。
webp は Read で読めないことがあるので、`sips -s format jpeg` で scratchpad に変換してから目視する。

## このスキルが防ぎたいこと

過去の記事で、工程セクションが次のようになり、読み手が作業をイメージしにくかった。

1. 写真が作業中の手元だけで、そのパーツが本体のどこなのか、塗り終わるとどうなるのかが分からない
2. 「胴体を塗る」「腕を塗る」のように部位ごとに分けた結果、中身が同じ話の繰り返しになり、本文のないステップができた
3. 前半で予告した「素組みで足りないところを塗装で補う」「今回試す技法」が、工程のなかで薄くなった

## 手順

1. 塗装メモを目視し、次を書き出す
   - テーマ（カラーリングの狙い）
   - 写真上の注釈と、それが指している部位
   - 箇条書きの項目（改造・塗装・任意の作業）
   - 「★」など、今回の挑戦として目印がついた項目
   - 素組みで気になったところ（なぜその塗装をするか）
2. 項目をステップにまとめる。区切り方のルール:
   - 「何を判断・工夫したか」で区切る。部位ごとには分けない
   - 部位ごとのサブステップ（`number={2.1}` など）は、塗り方や使う技法が部位によって違うときだけ使う
   - 調色に工夫がある色（「黒は少しでも影響力強いので青多め」など）は、塗るステップとは別に「〇〇色を作る」として立てる
   - 素組みで気になったところは、それぞれ回収するステップを1つ持たせる
   - 今回の挑戦はステップとして独立させ、写真を多めに撮る
   - 「元気なかったらしないかも」のような項目は、タイトル末尾に「（任意）」をつける
   - 工程順は、下地 → 調色・塗装 → 細部の塗り分け → スミ入れ・ウェザリング → はみ出し補正 → トップコート を基本に、メモの内容に合わせて並べ替える
3. ステップごとに撮影リストを作り、各 `<BuildStep>` の中にコメントとして入れる。各ステップで次の3種類を基本にする
   - **手元:** 作業中のカット
   - **結果:** 塗り終わった状態。できれば手元と同じパーツ
   - **位置:** そのパーツが本体のどこか分かる引きのカット。組み上げてから撮る場合は、完成撮影のときに撮るものとして分けて書く
   - 素組みで気になったところを回収するステップでは、**メモの写真と同じアングルで塗装後を撮る**よう指示する
4. メモから読み取れない情報は推測で埋めず、それが必要なステップのコメントに「要確認:」として書く
   - 素組みで気になったところの理由
   - 今回の挑戦の目印
   - 色のレシピ

## 出力

`<BuildStepGroup>` の骨組みをコードブロックで1つ出す。これ以外は出さず、同じ内容をチャットに繰り返さない。
制作中はこの骨組みだけを見れば済むよう、撮影リストも、メモのどの項目をどこで回収するかも、すべてMDXコメントとして各ステップの中に入れる（ページには表示されない）。

- 画像は `{ src: "", alt: "", caption: "" }` の空スロットにし、枚数は撮影リストに合わせる
- 本文は `xxx` にする。まだ作業していないので、結果や感想は書かない
- コメントは `撮影` / `回収:` / `要確認:` の3種類。そのステップに関係するものだけ書く
  - **撮影:** そのステップの撮影リスト。制作中に `- [ ]` を `- [x]` に変えて進捗を管理できるよう、1行にまとめずチェックリストのまま書く
  - **回収:** そのステップで回収するメモの項目と、記事で見せたいこと。対応表としてまとめず、ステップごとに分けて書く
  - **要確認:** メモから読み取れなかったことのうち、そのステップを書くのに要るもの
- 複数のステップにまたがる項目（テーマなど）は、回収が始まるステップに1度だけ書く
- 組み上げてから撮るものと、完成で回収する項目は、`</BuildStepGroup>` の直前にまとめる

```mdx
<BuildStepGroup>
  <BuildStep
    number={1}
    title="下地に白のプライマーを塗る"
    images={[
      { src: "", alt: "", caption: "" },
      { src: "", alt: "", caption: "" },
    ]}
  >
    {/*
      撮影
      - [ ] 手元: 筆でプライマーを塗っているところ
      - [ ] 結果: 塗り終わったパーツを並べたカット

      回収: メモの「xxx」。記事では xxx を見せる
      要確認: プライマーの製品名
    */}
    xxx

  </BuildStep>
  {/*
    完成撮影でまとめて撮るもの
    - [ ] メモの写真と同じアングル

    回収: メモのテーマ（xxx）。素組みと塗装後を同じアングルで比べる

\*/}

</BuildStepGroup>
```
