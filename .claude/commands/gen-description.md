ブログ記事のdescription（メタディスクリプション）とタイトルのキャッチコピーを生成してください。

## 対象ファイル

`$ARGUMENTS` で指定されたMDXファイルを読み込んでください。
引数が空の場合は、対象のファイルパスを聞いてください。

## 手順

1. 対象のMDXファイルを読み込む
2. フロントマターと本文の内容を把握する
3. 以下のルールに従ってdescriptionとキャッチコピーをそれぞれ生成する
4. 生成した内容をユーザーに提示し、承認されたらフロントマターを更新する

## descriptionの生成ルール

- **100〜120文字**（日本語）にする
- 記事の要点・結論を含め、検索ユーザーが「この記事を読めば知りたいことがわかる」と感じる内容にする
- 記事で扱っている製品名・キーワードを自然に含める
- 煽りすぎず、記事の内容に忠実な表現にする
- 文末は「〜を紹介します。」「〜を解説します。」「〜をまとめました。」など、内容に合った形で締める

## キャッチコピーの生成ルール

- **20文字以内**（日本語）を目安にする
- タイトルの `| ` 以降に入る形式（例: `メガロマリア ルビーアイ 筆塗り塗装 | ほんのり赤みがかった白を目指して`）
- 記事のメインテーマ・こだわりポイント・制作意図を一言で表す
- 複数候補（3〜4案）を提示する

## 出力

1. 生成したdescriptionとその文字数を表示する
2. キャッチコピーの候補を複数表示する
3. ユーザーに確認を取る（descriptionとキャッチコピーそれぞれ）
4. 承認されたら、フロントマターの `description` フィールドと `title` フィールドのキャッチコピー部分を更新する
