# プラモデル制作記事：読者ニーズとコンテンツ設計

## 1. どんな読者がいるのか

プラモデル制作記事を読む人には、主に次の3つの目的がある。1人の読者が複数の目的を持つこともある。

<!-- markdownlint-disable MD033 -->

| 読者                 | 想定検索                                                                            | 状況                                                         | 欲求                                                     | 必要な情報                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **① 作例を見たい**   | 「［キット名］ 作例」<br>「［キット名］ 塗装」<br>「［作品名］ プラモデル 完成」    | 購入検討中<br>所持済み<br>好きなキットの別の仕上げ方が見たい | 完成形を楽しむ<br>配色・ポージング・改造のアイデアを得る | 完成写真（全体・別角度・細部）<br>作品の特徴・見どころ<br>配色や加工の意図                       |
| **② 再現したい**     | 「［キット名］ 使用塗料」<br>「［キット名］ 筆塗り」<br>「［キット名］ 改造 方法」  | 気に入った作例の色や工作を自分の制作に取り入れたい           | 材料・工程・判断のポイントを具体的に知る                 | 使用キット・追加パーツ<br>塗料名と色番号・塗装箇所<br>主な工作・塗装手順<br>仕上がりのアップ写真 |
| **③ 技法を学びたい** | 「プラモデル 筆塗り ムラ 対策」<br>「合わせ目消し コツ」<br>「ウェザリング やり方」 | 特定の作業に困っている<br>新しい技法を試したい               | やり方<br>うまくいく条件<br>失敗と対処法                 | 作業中の写真・工程ごとの比較<br>道具の使い方・注意点<br>失敗例と改善結果                         |

## 2. 制作記事では誰をメインターゲットにするか

### 基本方針（初期仮説）

通常の「作品制作記録」であれば、**① 作例を見たい人**と**② 再現したい人**を主な対象にする。

**③ 技法を学びたい人**には、その作品で特に重要だった技法・失敗例を紹介する。ただし、技法自体が記事の主題は制作記事ではなく、HowTo記事として制作する。

### メインターゲット像

> 対象キットに興味があり、ほかの人がどう組み立て・加工・塗装して仕上げたのかを知りたい模型好きの人。気に入った表現を自分でも取り入れたい。

### ユーザーストーリー

> 「［キット名］をどんなふうに仕上げられるか知りたい。完成した姿を見て、配色や使用材料、実際の作り方から、自分の制作に使えるヒントを見つけたい」

### 読了後の理想的な状態

> 「この仕上げ方いいな。どこをどう工夫したかもわかったから、自分でも試してみよう」

### 記事で優先すべきこと

1. **完成形がすぐ伝わる**：冒頭で作品全体と特徴がわかる。
2. **何をどう変えたかがわかる**：配色・加工・塗装の意図と結果を確認できる。
3. **再現の手がかりがある**：使用した塗料・道具・パーツや重要な工程がわかる。
4. **実体験に基づく発見がある**：難しかった点、試してよかった方法、注意点がわかる。

### 記事ごとに決め直す項目

- **対象作品**：［キット名・グレードなど］
- **最も届けたい読者**：［①／②／③、または組み合わせ］
- **読者の中心的な疑問**：［この記事で解決したいこと］
- **この記事ならではの価値**：［独自の配色、加工、検証、失敗と学びなど］
- **読了後に取ってほしい行動**：［作品を参考にする、塗料を調べる、技法を試すなど］

## 3. 読者の欲求から必要なコンテンツ・セクションを逆算する

| 読者の疑問                 | 用意するとよいコンテンツ・セクション         | 向いている写真・資料                       |
| -------------------------- | -------------------------------------------- | ------------------------------------------ |
| どんな作品になった？       | 完成作品の紹介、見どころ                     | 全体・別角度・ポーズ写真                   |
| 元のキットと何が違う？     | 制作方針、配色・加工のポイント               | 素組みとの比較、改造箇所のアップ（あれば） |
| どんな色・材料を使った？   | 使用塗料・道具・追加パーツと使用箇所         | 塗料・道具、該当部位のアップ               |
| どうやって仕上げた？       | 重要な工作・塗装工程                         | 作業中、工程ごとの結果がわかる写真         |
| 自分で作るときの注意点は？ | 難しかった点、対処法、やり直すなら変えること | 問題のあった箇所、修正前後の比較（あれば） |
| 仕上がりは満足できた？     | 完成後の評価、気に入った点と課題             | お気に入りの完成写真・部分アップ           |

### セクション設計で意識すること

- **「作者が何をしたか」だけでなく「読者が何を知れるか」で見出しを決める。**
  - 例：「制作コンセプト」→「どんな仕上がりを目指したか／なぜこの配色にしたか」
  - 例：「苦労したこと」→「塗り分けで難しかった点と対処法」
- **写真は撮影時期ではなく役割で選ぶ。** 完成写真は結果を示すため、作業中の写真は方法を伝えるために使う。
- **すべての制作工程を載せる必要はない。** 読者の疑問に答える工程を優先する。
- **写真がない内容を無理に補わない。** 後撮りできる完成写真は補い、存在しない途中経過や曖昧な条件は推測で書かない。
- **記事に必要のないセクションは省く。** 改造していないなら改造編は不要。使用塗料の詳細を別記事にまとめる選択肢もある。

---

## 記事設計の判断基準

**読者が「作品を楽しめる」「仕上げ方を理解できる」「自分の制作に活かせる」ことを中心にする。**

記事の主役が完成作品なのか、制作工程なのか、特定技法なのかによって、必要なセクションや写真の比重を調整する。
